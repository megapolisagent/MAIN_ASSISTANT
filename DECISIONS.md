# История и статус решений

> Не журнал. `HOME.md` сверяется с этим файлом при значимых решениях.

## Как решение становится фактом

```
Proposal → Discussion → Locked
```

Переход между статусами разрешён только по явному подтверждающему слову владельца («принимаем», «фиксируем», «зафиксируй», «LOCKED») — никогда не выводится из тона реплики.

## Правила

- **Отклонённые альтернативы не удаляются.** Остаются в записи со статусом «отклонено» и причиной.
- **После Locked — заморозка.** Обсуждение отклонённых вариантов прекращается немедленно.
- **Решение не пересматривается без нового факта.**
- **Rule Promotion Policy** (`HOME.md`, «Правила») — изменения поведения агента требуют L3+ (2+ независимых подтверждённых случая), кроме Human Override — явного решения владельца в моменте, фиксируется как L1, не выдаётся за L3+.

## Формат записи

```
### {дата} — {короткое название решения}

Статус: Proposal / Discussion / Locked / Отклонено
Что решается:
Обоснование:
Отклонённые альтернативы:
Источник:
```
