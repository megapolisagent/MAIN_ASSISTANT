# Границы работы в папке «Главный ассистент» (в Antigravity нет защитных хуков, эти правила держатся только текстом)

1. **Секреты.** Не открывай и не выводи файлы окружения (`.env` и родственные), `.mcp.json`, локальные настройки Claude (`.claude/settings.local.json`), файлы с ключами, токенами и кэшем токенов, ничего из `~/.ssh`. Ключ в чат не просить и не записывать в файлы.
2. **Ничего наружу.** Никаких отправок сообщений, публикаций, платежей, `git push`, деплоя, регистраций. Вызывать платные API и сервисы с ключом нельзя. Только бесплатные открытые источники. Особо запрещено: запускать `update.sh`. Личные мысли и решения Марии не выноси за пределы этой папки.
3. **Личные аккаунты.** Не входи в аккаунты Марии (Telegram, YouTube, Google, Авито), не используй Telethon, Pyrogram и MTProto-сессии. Telegram читай только через публичную страницу `https://t.me/s/<имя>` без входа.
4. **Защиту не обходить.** Капча, блокировка, лимит запросов: остановись, запиши в отчёт, предложи другой источник. Не подменяй адреса и не ротируй прокси.
5. **Персональные данные.** Не сохраняй имена, ники, телефоны людей из комментариев и чатов. Сохраняй текст, дату, источник и ссылку.
6. **Зоны записи.** Пишешь только в `workspace/`. `scripts/` и `tests/` правишь, только если так сказано в задаче. Всё остальное в папке только читаешь: `CLAUDE.md`, `AGENTS.md`, `MEMORY.md`, `PROFILE.md`, `MISSION.md`, `ROLE-CONTRACT.md`, `.claude/`, `.agents/`, `knowledge/`, `memory/`, `docs/`, `data/`. Чужие файлы в `workspace/` не переписывай: сделай рядом новую версию с датой в имени.
7. **Папки других агентов закрыты для записи.** Всё за пределами этой папки (`../Skill System`, `../Motion Director` и любая другая рядом) только читаешь: ничего там не создаёшь, не правишь, не удаляешь, не запускаешь скрипты, которые пишут туда, и не коммитишь. Нужная правка там: опиши её в `workspace/` отдельным файлом (что менять, в каком файле, зачем), а в `RETURN` напиши, что требуется правка; её сделает Claude Code. Единственное исключение: Мария прямо говорит «Да, делай» про конкретное действие в конкретной папке; слово относится только к названному действию. Сказанное в разговоре про другую тему этим словом не считается.
8. **Большое не читай целиком.** Выгрузки и страницы обрабатывай скриптом и работай с компактным итогом.
9. **Что не сделал или не проверил, называй прямо.** Не выдавай расчёт на глаз или чтение кода за проверку.

# Эстафета Claude Code ↔ Antigravity

Когда у Claude Code кончаются лимиты, Мария открывает эту папку в Antigravity и ставит задачу словами. Правила, чтобы мы не мешали друг другу:

**Для Antigravity**
1. Первым действием `git branch --show-current`. Если ветка не `agy/work`: `git switch agy/work` (нет такой ветки: `git switch -c agy/work`). Git отказывает из-за несохранённых изменений: остановись, скажи Марии, ничего не сбрасывай и не удаляй. Коммить только в `agy/work`; в `main` не коммить и не сливай, `git push` нельзя.
2. Прочитай `CLAUDE.md`, затем состояние: `MAIN_ASSISTANT_STATE.md` и `MEMORY.md`. Из `workspace/` читай то, что относится к задаче.
3. Результат клади в `workspace/` (зоны записи выше).
4. В конце запиши `workspace/antigravity/RETURN-<ГГГГ-ММ-ДД>.md`: что сделано, что в работе, пути файлов, что не проверено; закоммить в `agy/work`.
5. «Готово» только с выводом запуска или проверки.

**Для Claude Code**
1. На старте: `git branch --show-current` и `git log main..agy/work --oneline`. Если ветка `agy/work` ушла вперёд, сначала приёмка: читаю `RETURN-*.md`, `git diff main...agy/work`, проверяю по файлам. Принято: `git switch main`, `git merge agy/work`. Не принято: возвращаю замечания Марии простым языком, не исправляю молча.
2. Пока в `agy/work` есть непринятая работа, файлы, которые она меняет, не правлю.
