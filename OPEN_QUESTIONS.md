## Журнал — Mode B-кандидаты

> При создании каждый проходит 4-вопросный gate из `HOME.md`: нужен ли вообще → горизонт цикла 30–90 дней → метрика обоснования → допустимость одноразовой задачи. Кандидат — это «требует gate-проверки», не «будет создан».

### Кандидат-1: Агент для семейной проработки

Сфера: Дети/Родители. Контекст запроса: «хочу сама простроиться — быть взрослой». Что проверить через gate: повторяющийся контур минимум 30–90 дней проработки? Какая метрика прогресса? Это работа для AI-агента или для живого специалиста (психолог, семейный терапевт)?

### Кандидат-2: Агент для проработки финансового паттерна

Сфера: Саморазвитие → Финансы. Контекст запроса: «избавляюсь от денег, не уверена что могу заработать». Что проверить: AI-агент или живой специалист? Какая метрика? Граница между когнитивной проработкой и психотерапией.

### Кандидат-3: AI-агент для английского — статус обновлён 2026-08-19, уже не просто кандидат

Сфера: Саморазвитие/Дети (сын, 8 класс). Прошёл дальше, чем «кандидат» — реальная сессия проектирования состоялась 2026-07-15/16, архитектура согласована (Student Digital Twin, Summer Recovery + School Mode, LOCKED-решения). Полный Engineering Handoff — `knowledge/projects/english-tutor-handoff.md`. Единственный блокер: нужен учебник (название/класс/издательство), без него не написан System Prompt. Не запущен, ждёт этого шага, не ждёт gate-проверки заново.

### Кандидат-4: AI-агент для Красной Поляны

Сфера: Путешествия. Контекст: срочный — скоро поездка. ⚠️ Предварительная оценка через gate: разовая задача (одна поездка). Вопрос 2 (горизонт 30–90 дней) скорее всего отсекает — это не агент, а Mode A или Mode C-инструмент. Скорее всего НЕ агент. Проверить через gate явно.
